## About the project

[Cakrawala University](https://www.cakrawala.ac.id/) focuses on industry-oriented education, with flexible learning supported by technology. The project I joined was building two systems for the university: SPMB, its online admissions system for prospective students, and an in-house academic information system (SIAKAD).

I contributed to both systems during my Full-stack Engineer internship at Dibimbing.id.

## My responsibilities

- Researched Node.js and Go for the backend, weighing expected traffic spikes, concurrent requests, performance, and the team's familiarity with each option.
- Shared the findings that informed the team's choice of Go with Fiber for the backend and Next.js for the frontend.
- Built frontend and backend features for shortlist registration and student biodata.
- Implemented administrator workflows for biodata verification and maintenance-condition tracking.
- Set up frontend formatting and linting with ESLint and Prettier.
- Configured a multi-stage Docker build for the frontend.

This work gave me hands-on experience contributing across the stack, from technical research and implementation to frontend quality checks and container builds.

## Stack

Next.js, Go Fiber, PostgreSQL, Redis, and Docker.
